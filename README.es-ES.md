

# Awwwards: Una Landing Page Moderna con React

Una aplicación de landing page de React de alto rendimiento, construida con tecnologías web modernas y mejores prácticas.
Replica parte de la landing page de [Zentry](https://zentry.com/).

## 🚀 Tecnologías

- React 19
- TypeScript
- Tailwind CSS
- React Suspense
- Code Splitting

## ⚙️ Instalación

```bash
# Clonar repositorio
git clone https://github.com/AhmedHanye/awwwards.git


# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

# 🎯 Características

- Carga dinámica de componentes
- Rendimiento optimizado con code splitting
- Diseño responsivo
- UI/UX moderna
- Integración con TypeScript
- Gestión de estados de carga

# ⚡ Rendimiento

La aplicación implementa varias optimizaciones de rendimiento:

- Carga diferida (lazy loading) de componentes
- Suspense para estados de carga
- Code splitting basado en rutas
